# Guide Image Research Library

This directory is the Guidebook 2.0 navigation index for externally hosted *Last War: Survival* guide images, charts, maps, spreadsheets, planners, and image-heavy guides.

No image binaries are automatically downloaded or stored here.

## Start here

- [`manifest.md`](manifest.md) — topic navigation
- [`schema.md`](schema.md) — normalized manifest-entry format
- [`manifests/`](manifests/) — topic-specific research manifests

## Organization

Resources are split by game topic rather than by source site. Major groups include:

- Alliance Duel / VS
- Arms Race
- Alliance and daily systems
- Battlefields
- Capitol / Warzone warfare
- Alliance Exercise
- PvE and recurring events
- Shops and event calendars
- Progression and account development
- Seasons 1–6
- Broad source hubs

Each item-level entry should link to the most specific useful resource available. Generic source directories are kept separately in the source-hubs manifest.

## Research use

An entry means the source may be useful for extracting, translating, comparing, or verifying game data. It does not mean every claim in the source has been independently verified.
